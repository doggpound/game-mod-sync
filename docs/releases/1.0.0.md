**The Go version:** one program for Windows, macOS and Linux, with nothing else to install.

- Syncs a mod-manager profile's mods and config files to a game server over SSH, or SFTP alone
- Shows what will change first, and backs up what it replaces
- Full-screen and text interfaces
- Downloads the server's world to test mod updates locally (Valheim)
- Plugins for mod managers, mod loaders, server types, world formats and games

Coming from 0.x? Your settings are converted on first start.
